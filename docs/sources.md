# Primary source review

Purpose: distinguish the frozen corpus, manual primary-site spot checks and model assumptions. Reviewed 2026-10-21 America/Detroit; cache fetch timestamps after 00:00 UTC read 2026-10-22.

- [SEC submissions index, CIK 1050446](https://data.sec.gov/submissions/CIK0001050446.json): discovery snapshot under `data/raw/submissions/`. `data/filings.csv` records every candidate 8-K/8-K/A and its parse/skip reason. Discovery uses the recent index only, not the historical-index pagination API. Coverage is the frozen listed corpus, not an assertion that no earlier/amended filing exists.
- [October 19, 2026 8-K](https://www.sec.gov/Archives/edgar/data/1050446/000119312526424688/mstr-20261019.htm), manually reopened in the browser on October 21: BTC Update reports 267 BTC purchased for $22.1M; 848,517 BTC held. ATM table reports 140,872 MSTR shares sold for $22.0M net. USD section reports $4.83B Reserve and $447.3M Cash as of October 18. Values/units are preserved in the cached source and normalized evidence lines.
- [Q2 2026 10-Q](https://www.sec.gov/Archives/edgar/data/1050446/000105044626000044/mstr-20260630.htm), manually reopened October 21: cover reports 364,585,501 class A and 19,640,250 class B shares as of July 24; filed August 3. This is a cover-date basic-share count, not June 30 diluted shares or an October denominator.
- [October 16, 2026 8-K, document dated October 15](https://www.sec.gov/Archives/edgar/data/1050446/000119312526423400/mstr-20261015.htm), manually reopened October 21: daily STRC dividends for November are conditional. [Company proposal FAQ](https://www.strategy.com/it/mstr/vote), also reopened, says the October 28 vote must approve the amendments. Daily dividends are **not treated as enacted as of October 21**. The parser skips this non-weekly filing rather than turning it into a weekly metric.

All other numerical coverage is exercised by offline parsing of actual SEC HTML, not separate manual browser inspection of every filing. Original bytes have URL, fetched UTC, SHA-256 and byte size in the manifest. `python -m ledger hydrate` verifies all 184 cached resources, including indexes and exhibits. No synthetic fallback is used. The hydrated cache is ignored; original public source bytes are bundled in `data/sources/sec-sources.zip`, with manifest and normalized outputs frozen as small CSV shards.

`dat-accretion` was read for its SEC client, HTML block reader and heading/parser approach. It was not edited. Source lineage is documented in `method.md`. No assertion is made that the original code has an independently selected reuse license; this local continuation adds no license.
